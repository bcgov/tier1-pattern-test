# Overview

`greet(name)` returns a greeting string in the format `"Bonjour, <name>!"`.

- **Parameter**: `name` (string, default: `"world"`)
- **Returns**: A string such as `"Bonjour, world!"` or `"Bonjour, Alice!"`
